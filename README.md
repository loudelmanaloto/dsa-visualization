# Data Structure Stepper

Interactive, step-by-step visualizations of stacks, queues, hash tables (chaining and linear probing), five sorting algorithms (bubble, selection, insertion, merge, quick), binary search trees with in-order, pre-order, post-order and level-order traversals, and graphs (DFS, BFS, Dijkstra, Prim–Jarník, Kruskal). Every operation can be stepped through with Next / Prev or played as an animation, with a plain-language explanation and highlighted pseudocode for each step.

Single static page (`index.html`), no build step. Hosted with GitHub Pages.

## Activities

The **Activity** tab (`#activity`) is a hub with seven graded activities: one 25-item activity per topic (20 concept and tracing items plus 5 terminology items) (`#activity-stack`, `#activity-queue`, `#activity-hash`, `#activity-sorting`, `#activity-tree`, `#activity-graph`) plus the original 13-item mixed review (`#activity-mixed`). Each student gets their own numbers, generated from their student ID. Answers are graded in the browser when submitted, and students download a result PDF to upload to the class submission page.

Each topic tab also has a filterable **Key terms** glossary. The terms live in `window.DSA_GLOSSARY` and feed the terminology items.
