# Data Structure Stepper

Interactive, step-by-step visualizations of stacks, queues, hash tables (chaining and linear probing) and five sorting algorithms (bubble, selection, insertion, merge, quick). Every operation can be stepped through with Next / Prev or played as an animation, with a plain-language explanation and highlighted pseudocode for each step.

Single static page (`index.html`), no build step. Hosted with GitHub Pages.

## Mini activity

The **Activity** tab (`#activity`) is a 13-item tracing exercise. Each student gets their own numbers, generated from their student ID. Answers are graded in the browser when submitted, and students download a result PDF to upload to the class submission page.
